# Instruções do projeto

## Objetivo
Criar uma landing page para vender 260 cards ilustrados de
decoração em PDF para moradores.

Público inicial: pessoas com a sala mobiliada que querem avaliar
combinações e pequenos ajustes antes de comprar outra peça.

## Fontes de informação
- Leia docs/briefing-lp.md antes de implementar.
- Leia docs/oferta.md para informações comerciais.
- Use imagens reais de public/images/.
- Consulte referencias/ quando houver arquivos relevantes.
- Não invente dados ausentes. Informe conflitos entre os documentos.
- Consulte os PDFs de materiais-produto/ para verificar o conteúdo
  real dos cards e as instruções do manual.
- Se uma informação comercial estiver marcada como PENDENTE,
  não invente um valor nem a apresente como confirmada.

## Implementação
- Inspecione o projeto e reutilize a stack existente.
- Se estiver vazio, prefira HTML, CSS e JavaScript simples.
- Use dependências apenas quando houver necessidade concreta.
- Centralize preço, checkout e condições comerciais.
- Não publique PDFs completos do produto.
- Não crie backend ou autenticação sem necessidade.

## Design
- Identifique as skills e os MCPs realmente disponíveis e use
  os que contribuírem para leitura dos materiais, design,
  implementação e verificação visual.
- Inclua a skill frontend-design instalada, respeitando o briefing.
- Desenvolva uma composição própria para este produto.
  Não reproduza automaticamente exemplos ou padrões da skill.
- Não use ferramentas apenas por estarem disponíveis.

## Conteúdo
- Não invente depoimentos, avaliações, descontos ou escassez.
- Não prometa projeto personalizado ou resultados garantidos.
- Deixe claro que o produto é digital e imprimir é opcional.
- Não apresente arquivos como editáveis.

## Verificação
- Confira layout em 360 px, 390 px e desktop.
- Verifique amostras ampliáveis, links, CTAs e checkout.
- Execute as verificações apropriadas à stack.
- Não declare revisão visual sem abrir a página.
- Informe verificações que não conseguiu executar.

## Autonomia
Prossiga com decisões reversíveis de implementação.
Não publique, faça deploy ou instale integrações externas
sem solicitação explícita.

## Materiais e publicação
- Os PDFs completos em materiais-produto/ são entregáveis pagos.
- Não copie esses PDFs para public/ nem para a saída de publicação.
- Não crie links públicos para os PDFs completos.
- Não configure a raiz inteira do projeto como diretório público.
- Exporte somente as amostras selecionadas para public/images/.
- Preserve os textos, as ilustrações e as proporções das amostras.
